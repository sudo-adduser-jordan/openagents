# open-agents orchestrator

Manage orchestrator sessions.

## Syntax

```
open-agents orchestrator <subcommand> [flags]
```

## Subcommands

---

### open-agents orchestrator ls

List orchestrator sessions. Aliases: `ls`, `list`.

**Syntax:**
```
open-agents orchestrator ls [flags]
```

**Flags:**

| Flag | Meaning | Default / Required |
|---|---|---|
| `--json` | Output as JSON | - |

## Examples

```bash
# List all orchestrator sessions
open-agents orchestrator ls
```

```bash
# List orchestrator sessions as JSON
open-agents orchestrator ls --json
```
