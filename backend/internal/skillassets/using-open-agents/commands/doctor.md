# open-agents doctor

Run local Open Agents health checks. Use this to diagnose setup problems or verify the environment is correctly configured.

## Syntax

```
open-agents doctor [flags]
```

## Flags

| Flag | Meaning | Default / Required |
|---|---|---|
| `--json` | Output health checks as JSON | - |

## Examples

```bash
# Run health checks
open-agents doctor
```

```bash
# Get health check results as JSON
open-agents doctor --json
```
