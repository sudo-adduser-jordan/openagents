# open-agents manager

Manage manager sessions.

## Syntax

```
open-agents manager <subcommand> [flags]
```

## Subcommands

---

### open-agents manager ls

List manager sessions. Aliases: `ls`, `list`.

**Syntax:**
```
open-agents manager ls [flags]
```

**Flags:**

| Flag | Meaning | Default / Required |
|---|---|---|
| `--json` | Output as JSON | - |

## Examples

```bash
# List all manager sessions
open-agents manager ls
```

```bash
# List manager sessions as JSON
open-agents manager ls --json
```
