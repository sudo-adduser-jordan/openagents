---
title: Aider
description: Built-in Terminal UI support for a local Aider installation.
---

Open Agents resolves `aider` from your machine and leaves model credentials to Aider's normal configuration.

```bash
open-agents agent ls --refresh
open-agents spawn --project my-app --name aider-task --agent aider --mode tui
```

Aider is currently Terminal UI-only. It does not have an Open Agents structured Chat driver, so `--mode chat` is rejected explicitly.

Use project `agentConfig` and environment settings for supported model/permission overrides. Agent adapters are compiled into Open Agents; there is no separate Aider plugin package or YAML plugin block.
