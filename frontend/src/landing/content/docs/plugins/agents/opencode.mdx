---
title: OpenCode
description: Built-in Terminal UI and native ACP Chat support for the user's OpenCode installation.
---

Open Agents resolves your local `opencode` executable and reuses its authentication.

```bash
open-agents agent ls --refresh
open-agents spawn --project my-app --name opencode-task --agent opencode --mode chat
```

OpenCode can run as its native Terminal UI or through its native ACP interface in structured Chat. Chat history is persisted by Open Agents as a durable, paged conversation projection while provider conversation identity is retained for continuity.

OpenCode is also a shipped reviewer harness. Reviewer configuration is independent from the worker harness; inspect project settings and `open-agents review --help` for the current review workflow.
