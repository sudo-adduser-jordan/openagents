---
title: Cursor
description: Built-in Terminal UI support for the Cursor Agent CLI.
---

Open Agents's Cursor adapter resolves the Cursor Agent CLI from your machine and checks its local readiness through the agent catalog.

```bash
open-agents agent ls --refresh
open-agents spawn --project my-app --name cursor-task --agent cursor --mode tui
```

Cursor is currently Terminal UI-only; requesting `--mode chat` fails with an unsupported-Chat error rather than silently creating a different interface.

Open Agents records activity through the adapter's supported hooks and terminal signals. There is no Cursor npm plugin or `open-agents.yaml` block to install.
